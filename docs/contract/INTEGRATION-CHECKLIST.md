# Подключение настоящей платформы

OpenAPI в этой папке — предложение контракта. Отдельный mock и HTTP-адаптер проверены вместе; это не подтверждает совместимость с закрытой Recsflow.

1. Сопоставить endpoints рекомендаций, batchGet, поиска названий и истории. Проверить IDs, пагинацию, размер пачки и смысл score.
2. Согласовать длительность: серия / фильм / весь курс. Неизвестное значение не проходит жёсткое ограничение.
3. Разделить viewed/liked и disliked. Пользователь должен определяться аутентификацией, а не доверенным полем запроса.
4. Согласовать неоднозначные названия; не выбирать случайный объект из нескольких совпадений.
5. Задать RECAGENT_PROVIDER=recsflow, RECAGENT_PROVIDER_URL и локальный ключ. В Compose адрес mock указан явно — его нужно заменить.
6. Указать RECAGENT_CONTRACT_URL на тестовую платформу и выполнить `python -m pytest tests/contract/test_platform.py -q`. PowerShell: `$env:RECAGENT_CONTRACT_URL='http://127.0.0.1:8090'`.
7. Проверить 429/Retry-After, 5xx, таймаут, неполные метаданные и восстановление breaker. Без метаданных возвращаются только IDs, без обещания соблюсти фильтры.
8. Измерить качество на реальных профилях и нагрузку при согласованном SLA.

Приёмка: подтверждённая схема, изоляция пользователей, контрактные тесты на staging, отсутствие вымышленных атрибутов, наблюдаемые отказы и согласованная нагрузка.
