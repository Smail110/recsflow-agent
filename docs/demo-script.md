# Показ прототипа за 3 минуты

0:00–0:20. Открыть чат. Обозначить границу: синтетический каталог, реального API нет, архитектура предусматривает адаптер.

0:20–0:45. Ввести «Посоветуй что-нибудь», показать вопрос о формате, ответить «Лёгкий детективный сериал, один сезон».

0:45–1:15. Ввести «Не дольше 30 минут». Раскрыть «Диагностика запроса»: прежние genre/tone/seasons сохраняются. Показать поле minutes и карточку.

1:15–1:45. Раскрыть «На чём основан выбор»: объяснения связаны с атрибутами каталога. Нажать «Не подходит» у одного объекта и попросить «Ещё».

1:45–2:10. Новый диалог: «Курс по машинному обучению для новичка, без воды». Показать уровень и практику.

2:10–2:35. Переключить на Ollama. Повторить разговорный запрос, показать mode, попытки и токены. Если модель не запущена, честно показать fallback и его предупреждение.

2:35–3:00. Открыть REST `/docs` и HTML-отчёт. Назвать ограничения: небольшой синтетический benchmark, условный реранкер, память одного процесса. Показать `RecommendationProvider` как место будущей интеграции.

Это сценарий для скринкаста, не видеозапись. Не выдавайте показатели синтетического стенда за качество рекомендаций Recsflow.
