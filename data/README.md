# Датасет для Hugging Face

В этой папке нет реальных пользовательских данных. Перед обучением поместите сюда `dialogues.jsonl` через `scripts/prepare_hf_dataset.py`.

Одна строка должна содержать:

```json
{"text":"Хочу лёгкий детективный сериал на вечер", "label":"mood"}
```

Допустимые `label`: `discovery`, `similar`, `mood`, `navigation`. Не загружайте PII, токены или сырые логи без обезличивания и разрешения владельца данных. Разделяйте train/validation по пользователю или диалогу, иначе метрики будут завышены из-за утечки истории.
